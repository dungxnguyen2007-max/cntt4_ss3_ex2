# PHÂN TÍCH CẢM XÚC – 100 CUSTOMER FEEDBACKS

## Quy ước phân loại

-   **Positive**: khen thật, trải nghiệm tốt rõ ràng.
-   **Negative**: chê trực diện HOẶC "khen đểu/nói đểu/đá đểu" (khen bề mặt nhưng thực chất chê).
-   **Neutral**: trung tính, "bình thường", "tạm được", không khen chê rõ.
-   **Invalid**: rỗng, ký tự vô nghĩa, lỗi mã hóa, cắt cụt.
-   **score**: thang 1–5 (1 = rất tiêu cực, 5 = rất tích cực).
-   **summary**: ≤ 15 từ, đã lọc từ cảm thán thừa.
